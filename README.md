# CTH IPD Link Portal (ห้องยาผู้ป่วยใน โรงพยาบาลจอมทอง)

ระบบเว็บเพจศูนย์รวมลิงก์งานและคู่มือการปฏิบัติงาน สำหรับ **ห้องยาผู้ป่วยใน (IPD) โรงพยาบาลจอมทอง** ออกแบบให้ใช้งานง่าย การ์ดและไอคอนรูปภาพขนาดใหญ่ เหมาะสำหรับการกดบนหน้าจอคอมพิวเตอร์และแท็บเล็ตประจำห้องยา

---

## 🌟 คุณสมบัติเด่น (Features)

1. **การ์ดรูปภาพ/ไอคอนขนาดใหญ่ (Big Icon Cards):**
   - ปุ่มใหญ่ สัญลักษณ์ชัดเจน ตัวหนังสืออ่านง่าย มีแท็กกำกับระบบงาน
   - รองรับทั้ง **ไอคอนมาตรฐาน (Preset SVG)**, **URL รูปภาพภายนอก** และ **อัปโหลดรูปภาพจากคอมพิวเตอร์**

2. **ระบบจัดการลิงก์ (CRUD System):**
   - **เพิ่มลิงก์ (Add):** กำหนดชื่อ, URL, หมวดหมู่, แท็กย่อ (Badge), คำอธิบาย, สีธีมการ์ด และไอคอน
   - **แก้ไขลิงก์ (Edit):** ปรับปรุงข้อมูลหรือเปลี่ยน URL ลิงก์ได้ตลอดเวลา
   - **ลบลิงก์ (Delete):** พร้อมปุ่มยืนยัน ป้องกันการกดลบผิดพลาด

3. **โหมดความปลอดภัย (Admin / User Mode):**
   - **โหมดใช้งานทั่วไป (User Mode):** สำหรับเจ้าหน้าที่คลิกเปิดใช้งานลิงก์ ป้องกันไม่ให้กดแก้ไข/ลบโดยไม่ตั้งใจ
   - **โหมดจัดการลิงก์ (Admin Mode):** แสดงปุ่มเพิ่ม แก้ไข และลบการ์ดลิงก์

4. **การจัดหมวดหมู่ & ปักหมุด (Category & Pin):**
   - แยกหมวดหมู่ชัดเจน: ระบบงานสั่งยา, งานบริบาล/SOP, คลังยา/สต๊อก, รายงาน/สถิติ, ลิงก์ภายนอก
   - **ปักหมุด (⭐ Pinned Links):** นำลิงก์ที่ใช้งานบ่อยขึ้นมาแสดงในโซนพิเศษด้านบนสุด

5. **ค้นหา Real-time:**
   - ช่องค้นหาคำภาษาไทยและภาษาอังกฤษ ค้นหาได้ทั้งชื่อระบบ ลิงก์ แท็ก และคำอธิบาย

6. **ระบบสำรองและนำเข้าข้อมูล (Export / Import JSON):**
   - กดปุ่ม **"📥 สำรองข้อมูล"** เพื่อส่งออกไฟล์ `.json` ไปใช้งานหรือสำรองเก็บไว้
   - กดปุ่ม **"📤 นำเข้า"** เพื่อโหลดข้อมูลลิงก์เข้าสู่เครื่องคอมพิวเตอร์เครื่องอื่นๆ ในห้องยาได้ทันที

## 🚀 วิธีการใช้งาน (Getting Started)

### วิธีที่ 1: เปิดใช้งานผ่าน Web Browser โดยตรง
ดับเบิ้ลคลิกเปิดไฟล์ `index.html` ด้วย Google Chrome, Microsoft Edge, Safari หรือ Firefox

### วิธีที่ 2: รันผ่าน Local Web Server (Python)
เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วรันคำสั่ง:
```bash
python3 -m http.server 8080
```
จากนั้นเปิด Browser ไปที่: [http://localhost:8080](http://localhost:8080)

## 📂 โครงสร้างไฟล์ (File Structure)

- `index.html` - หน้าเว็บหลัก Single Page Application
- `css/styles.css` - ตกแต่งสไตล์ ธีมสุขภาพ/โรงพยาบาลจอมทอง และเอฟเฟกต์การ์ด
- `js/app.js` - ระบบการทำงานหลัก CRUD, LocalStorage, Modals และ Export/Import
- `js/defaultData.js` - ข้อมูลลิงก์เริ่มต้นของห้องยาผู้ป่วยใน CTH IPD
- `README.md` - เอกสารแนะนำการใช้งาน
